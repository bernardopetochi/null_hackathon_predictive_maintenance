# Simulated ULT freezer dataset (`ult_freezer_sim.csv.gz`)

Generated by `analysis/export_dataset.js` from the simulator in `index.html` (fixed seeds, reproducible).

- 300 simulated −80 °C two-stage cascade freezers: 150 Revco-like (fixed-speed compressor, 0.1 °C logging) and 150 Haier-like (variable-speed compressor, whole-degree logging).
- One row per freezer-hour. 80% of freezers develop one fault and run until they can no longer hold temperature; the rest run 3,000 healthy hours (125 days).
- Columns:

| column | meaning |
|---|---|
| freezer_id, brand | `revco_000`… / `haier_000`… |
| hour | hours since install |
| chamber_c | chamber RTD temperature, hourly mean (°C) |
| compressor_on_min | compressor on-time per cycle (min) |
| suction1_c, interstage_hx_c, evap_out_c, sump2_c | refrigerant-loop thermocouples (°C) |
| door_pulldown_min | time to pull back to setpoint after a door opening (min) |
| fault_type | `none`, `leak1` (refrigerant leak, stage 1), `comp1`, `comp2` (1st/2nd-stage compressor), `door` (door tightness / insulation); mixed 11:5:7:4 like the real Revco service log |
| fault_active | 1 once the fault has started |
| fault_severity | 0–1 hidden wear state (1 = failure) |
| hours_to_failure | ground-truth remaining useful life (blank for healthy freezers) |
| failed | 1 on the hour the freezer lost temperature |

Signal names and fault types follow the real Danish National Biobank dataset (Huang et al., Scientific Data 2023, doi:10.1038/s41597-023-02808-6) so models can later be tested on it. Fault sizes are calibrated on a hydraulic-rig proxy; healthy levels, lifetimes and the chamber warming curve are assumptions. See the main README.
